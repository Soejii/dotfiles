# Explanation Method

## Start with orientation

Give the gist before the details. Tell the user what problem the material is trying to solve and why the topic exists. A summary that only repeats headings is not an explanation.

## Follow dependency order

Introduce ideas in the order needed to understand later ideas, even when the source presents them differently. Define unfamiliar terms at first use. Connect each new idea to the previous one so the explanation forms a chain rather than a glossary.

## Explain relationships

Name the relationship precisely: cause, prerequisite, contrast, example, stage, category, method, outcome, or competing interpretation. Avoid vague connectors such as “related to” when a more exact relationship is available.

## Use concrete examples carefully

Prefer an example close to the user's course or assignment. Map each part of an analogy back to the academic concept, and state where the analogy stops working. Never let an analogy replace source evidence.

## Calibrate depth

Begin compactly, then deepen the part the user questions. Preserve necessary nuance without reproducing the source's full complexity at once. Use a small table or flow only when several relationships are materially easier to see that way.

## Preserve epistemic clarity

Use explicit labels when needed:

- **Source:** what the material directly states.
- **Interpretation:** the meaning reasonably drawn from it.
- **Simplification:** a teaching device that reduces complexity.
- **Unverified:** a claim that still needs a source or fuller context.

## Avoid common failures

- A textbook dump with every detail given equal weight.
- Replacing difficult words with different difficult words.
- Excessive headings and perfectly symmetrical bullet stacks.
- A summary that omits the mechanism or reasoning.
- Treating a group's outline as an established academic theory.
- Inventing certainty, citations, page locations, or author positions.
- Repeating the same explanation with minor wording changes.
- Quizzing the user before giving them anything useful.

## Re-pitch strategies

When the first explanation fails, choose a genuinely different route:

- Zoom out to the whole chapter or assignment.
- Zoom in to one disputed sentence or term.
- Walk through a causal chain step by step.
- Use a worked classroom or research example.
- Compare the concept against its nearest alternative.
- Begin from the outcome and reason backward.
- Sketch a compact relationship map.

State what changed in the re-pitch only if doing so helps the user orient themselves.
